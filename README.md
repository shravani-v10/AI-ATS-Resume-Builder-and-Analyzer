# AI-Based ATS Resume Analyzer and Resume Builder

## 📌 Project Overview

The **AI-Based ATS Resume Analyzer and Resume Builder** is a web-based application designed to help users optimize their resumes for job applications and create professional resume documents.

The application combines AI-powered resume analysis with resume-building functionality to simplify the resume preparation process.

## ✨ Key Features

### 1. AI-Based Resume Analyzer
- Analyzes resume content against a given job description.
- Uses the **Google Gemini API** to generate an ATS compatibility score.
- Identifies relevant keywords and skills from the job description.
- Provides suggestions and recommendations to improve resume content.

### 2. Resume Builder
- Allows users to enter, edit, and organize their resume details.
- Provides predefined resume templates.
- Generates professional resume documents.
- Allows users to download the completed resume in PDF format.

## 🛠️ Tech Stack

| Category | Technologies |
|---|---|
| Frontend | React.js, JSX, Tailwind CSS |
| Backend | Node.js, Express.js |
| Database | MongoDB |
| AI Integration | Google Gemini API |

## 🎯 Project Objective

The objective of this project is to make resume preparation easier by combining AI-assisted resume evaluation with a simple resume-building experience. It helps users identify gaps between their resumes and job requirements and create more relevant, professional resumes.
